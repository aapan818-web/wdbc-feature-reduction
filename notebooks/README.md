# 教学 Notebook 使用说明

`analysis.ipynb` 是项目的学习入口：按顺序理解原始数据、质量核查、统计分析、交叉验证、测试评价、特征选择及真实图形。

- 所有代码格初始 `execution_count=null`、`outputs=[]`。这份文件没有伪造已执行输出。
- 项目 `outputs/` 已有真实分析产物；大多数单元格仅读取这些文件。
- 完整重现统一调用根目录的 `run_analysis.py`，不在 Notebook 内维护第二套模型代码。
- 完整重跑单元格的 `RUN_FULL_ANALYSIS` 默认是 `False`。明确准备重跑时才设为 `True`；它会重新生成分析输出。
- 路径定位先检查当前目录与父目录，也兼容课程的“课程梳理/方案A项目”布局。不要把数据硬编码为本机绝对路径。
- Notebook 图形通过 Matplotlib 的 `plt.imread` 和 `plt.show` 显示，不依赖 IPython 的 `display`。

建议从项目根目录或 `notebooks` 目录打开 Notebook，并选择已安装 `requirements.txt` 所列依赖的 Python Kernel。Notebook 编辑界面由用户的 Jupyter 环境提供；本次没有为此另行安装 Jupyter、IPython 或 nbformat。若不使用 Notebook，也可按根目录 README 从命令行重现分析，再阅读生成的表格与报告。

**解释边界：**M=1、B=0；ID 不作为模型输入。统计分析、模型开发和最终测试各有不同作用。查看测试结果不能成为重新挑选模型、特征数或随机种子的理由。默认模型保留测试前的开发集选择；区间跨零不证明等效，特征减量不直接等于临床检查减量。

代码格顺序：

1. 定位项目根目录及读取配置。
2. 无表头读取原始 CSV 并解释 32 列与 30 个特征。
3. 读取质量与固定分区。
4. 可选调用完整复现脚本，默认关闭。
5. 读取真实结果与测试前冻结记录。
6. 阅读预设统计比较。
7. 阅读同折交叉验证与筛选名单。
8. 阅读最终测试指标。
9. 从真实预测手算 TP、FN 和恶性召回率。
10. 阅读成对 AUC 差与区间。
11. 阅读最终特征及五折频次。
12. 显示三张真实图形。

最后用六个自检问题确认理解程度；不要求此时扩展新模型或调整参数。
