# 潘冠宇的个人网站

网站以篮球、运动和生活表达为主，全球卫生学习与研究经历作为另一面。首页只有人物介绍、五个栏目入口和抖音账号；照片与详细内容在各自栏目中浏览。

| 路径 | 内容 |
| --- | --- |
| `/` | 个人首页，4 张精选封面 |
| `/sports/` | 比赛记录、篮球、腰旗橄榄球与其他运动，23 张照片 |
| `/research/` | 全球卫生背景、参与经历、实习和 WDBC 公开数据项目 |
| `/me/` | 自我介绍、爱好和生活照，17 张照片 |
| `/places/` | 旅行与风景，55 张照片，可按山野、水边、城市、校园筛选 |
| `/pets/` | 猫咪柠檬与路遇的小动物，7 张照片 |

路径相对于 GitHub Pages 站点根目录。每个栏目可以直接打开、复制链接和分享；没有创建外部短链服务。

## 内容与构建

- `content.json`：公开照片目录，包含文件名、尺寸、图注和分类。
- `../scripts/build_homepage.py`：页面内容和结构；生成本目录下六份 HTML。
- `assets/journal.css`、`assets/journal.js`：样式、筛选、分批展开与图片查看器。
- `../docs/assets/gallery/`：102 张去除元数据、保持比例的 WebP 网页图片。
- `../scripts/build_site.py`：统一构建入口，同时保留课程项目展示页。

修改内容或样式后，在仓库根目录运行：

```sh
python scripts/build_site.py
python -m http.server 8000 --directory docs
```

原图、简历和个人联系方式不作为网站附件。抖音公开账号为“潘潘潘冠冠 / 83008883411”，现有入口支持复制账号和打开抖音搜索。

照片在栏目内按需加载。无 JavaScript 时，照片仍可浏览、点击打开，导航和账号信息仍可用。图片查看器支持键盘方向键、Escape 关闭与触屏左右滑动。动画遵循减少动态效果设置。

## 内容依据

身份、赛事成绩、猫咪名称、旅行地点与双人合影展示范围来自作者确认。澳门大学邀请赛的最终名次为四强，证书的 First Prize 不被改写为冠军。科研经历据作者简历整理，参与职责与成果分别表述；在投稿件不展示。ENTP 是作者的自我标签。双人合影不标注关系。

栏目组织参考 [Maggie Appleton](https://maggieappleton.com/) 的主题入口和 [Derek Sivers](https://sive.rs/) 的短路径；摄影排版参考 [Craig Mod](https://craigmod.com/) 的留白与图文层次。本站使用作者提供的照片和原创页面代码。
