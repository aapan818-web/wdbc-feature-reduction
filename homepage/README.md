# 个人主页

首页面向同龄人，以篮球和生活表达为主，全球卫生专业背景为辅。个人定位、角色、赛事、抖音号和新增信息公开范围由作者在2026年11月14日确认。简历中的在投文稿按作者要求不展示；不以 MBTI 推断人格，不编写未提供的个人故事。

- 页面：`index.html`
- 样式和交互：`assets/`
- 照片：`../docs/assets/photos/`，保留原比例文件，去除元数据；页面用 CSS 适配版面。
- 构建：在项目根目录执行 `python scripts/build_site.py`。

抖音号是用户提供的公开账号标识，不等于平台使用的个人主页 URL。当前按钮复制账号并打开抖音首页；没有虚构 `/user/数字` 一类链接。获得作者分享的真实主页链接后可再替换为直达入口。

后续可以把此页面部署到独立个人网址。课程分析和报告仍保留在原项目中，作为一项作品。
